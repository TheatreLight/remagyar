# ReMagyar

Локальное Android-приложение на Flutter для изучения венгерских слов с русским переводом. Русский интерфейс, тёмная тема, карточки и прогресс хранятся на устройстве. Начальный банк пуст.

## Запуск

Проверенное окружение: Flutter 3.47.2, Dart 3.13.2, JDK 21, Android SDK 36. Установите Flutter и Android SDK, добавьте их инструменты в PATH и подключите Android-устройство с отладкой по USB.

```powershell
flutter pub get
flutter run -d <идентификатор-телефона>
```

Для установки через USB телефон должен разрешать не только отладку, но и установку приложений. Debug-сборка имеет идентификатор `hu.remagyar.remagyar.debug`, release — `hu.remagyar.remagyar`; их банки независимы.

## Как пользоваться

1. Добавьте слова вручную или нажмите «Загрузить ZIP» и выберите архив в описанном ниже формате.
2. В «Изучении слов» раскрывайте перевод и листайте карточки. Просмотр не меняет прогресс.
3. В «Повторении» напишите перевод, выберите один из четырёх вариантов или покажите ответ. Подсматривание считается неудачей.
   Карточки перемешиваются перед каждым повторением, включая давние слова; во время занятия порядок фиксирован.
4. Переключатель HU → RU / RU → HU меняет направление. Отметка успешного повторения общая.
5. «Повторить эти слова» выбирает слова без успеха либо с последним успехом не менее 120 часов назад.
6. Удаление доступно в банке слов. Повторный импорт удалённого слова создаёт его без прежнего прогресса.
7. «Удалить все» в банке слов после подтверждения удаляет все карточки, изображения, результаты и связи с группами. Сами группы сохраняются пустыми.

## Добавление и редактирование карточки

В «Изучении слов» значок карандаша на карточке открывает редактор. После сохранения карточка обновляется на том же месте занятия.

В «Банке слов» поиск обновляет список при вводе: ищет содержащие введённую часть венгерские слова и русские переводы, без учёта регистра. Это поиск подстроки; специальные символы регулярных выражений считаются обычным текстом. Очистка строки возвращает весь банк.

«Добавить слово» на главном экране открывает редактор. В банке слов нажмите на слово для редактирования. Обязательны венгерское слово и хотя бы один русский перевод; «Добавить перевод» позволяет ввести до пяти вариантов отдельными полями. Примеры и изображение PNG/JPEG необязательны. Изображение выбирается через системный выбор файла, его можно заменить или удалить.

Выберите несколько групп, создайте новые или отметьте «Без группы». Все изменения, включая новые группы, записываются только по кнопке «Сохранить». Возврат назад отменяет несохранённые изменения. Совпадение венгерского слова с другой карточкой блокирует сохранение по тем же правилам сравнения, что при импорте.

Изменение слова или списка переводов сбрасывает результат и timestamp. Правки примеров, изображения и групп сохраняют прогресс. База хранит переводы списком JSON: вручную указывать разделители не требуется.

## Импорт ZIP

После выбора архива укажите существующую группу, введите название новой или оставьте «Без группы». Одна группа применяется ко всем CSV в ZIP. Дубли карточек также включаются в выбранную группу, сохраняя переводы и прогресс. Названия групп уникальны без учёта регистра и пробелов по краям.

На главном экране «Все слова» открывает выбор нескольких групп и варианта «Без группы» для изучения и повторения. Общие карточки показываются один раз. Счётчики и действие «Повторить эти слова» относятся ко всему банку независимо от выбранных групп.

Значок папки в верхнем углу открывает управление группами: переименование и удаление. Без флажка «Удалить со словами» сохраняются все карточки. С флажком удаляются только слова, не входящие в другие группы; общие карточки и их прогресс сохраняются. Состав групп меняется в редакторе карточки.

При обновлении с версии без групп старые карточки сохраняются и доступны через «Без группы».

В корне ZIP должен находиться хотя бы один файл с расширением `.csv` (регистр расширения не важен). Имя произвольное: например, `words.csv`, `lesson-01.csv` или `Мои слова.csv`. Импортируются все CSV в порядке их расположения в архиве, одной транзакцией. Дубли между файлами пропускаются: сохраняется первое вхождение. Ошибка в любом файле отменяет весь импорт. В предупреждениях и ошибках указывается имя файла. Изображения JPEG/PNG при необходимости поместите в общую папку `images/` и укажите относительные пути. Папка images не нужна, если ссылок на изображения нет.

CSV: UTF-8, разделитель — запятая, четыре обязательных заголовка. Обязательные значения — венгерское слово и хотя бы один русский перевод. Несколько допустимых переводов разделяются `|`.

```csv
hungarian,russian,example,image
alma,яблоко,Ez egy alma.,images/alma.jpg
ház,дом|здание,Ez egy ház.,
```

Поля с запятыми и переносами заключайте в двойные кавычки, кавычки внутри удваивайте. Пример отображается как введён; его перевод можно включить в то же поле. Изображение необязательно, но указанная ссылка должна разрешаться в корректный файл.

Дубли венгерского поля пропускаются с предупреждением. При ошибке архива, строки или изображения весь импорт отклоняется. Изображения и карточки сохраняются одной транзакцией SQLite и не зависят от исходного ZIP.

## Проверки

```powershell
flutter analyze
flutter test --coverage
dart run tool/check_coverage.dart
flutter test integration_test/app_test.dart -d <идентификатор-телефона>
flutter test integration_test/card_editor_test.dart -d <идентификатор-телефона>
```

Модульные и widget-тесты используют реальную SQLite через FFI. Интеграционные тесты работают с отдельными базами в debug-приложении и удаляют их после успешного завершения. Они проверяют импорт, обучение и редактор; системный выбор файла проверяется отдельно на телефоне.

Отчёт покрытия — `coverage/lcov.info`. Проверка порога требует не менее 90% строк для импорта и логики повторения.

## Release APK

Для подписания создайте вне репозитория файл `key.properties` с полями `storeFile`, `storePassword`, `keyAlias`, `keyPassword` и укажите путь к нему в переменной окружения `REMAGYAR_SIGNING_PROPERTIES`. Альтернатива — исключённый из Git файл `android/key.properties`. В `storeFile` укажите абсолютный путь к своему keystore.

```powershell
flutter build apk --release
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

Готовый APK: `build/app/outputs/flutter-apk/app-release.apk`. Для обновления уже установленной release-версии используйте прежний ключ подписи. Без настройки ключа release-сборка не подписывается debug-ключом автоматически.
